## 🎨 Overview

The frontend client of **GSTBilling PRO** is a responsive Single Page Application (SPA) built with **React 19**, **Vite 8**, and **Tailwind CSS**. It incorporates an enterprise-grade dark/light theme, real-time GST tax calculation, PDF invoice rendering, role-based route guards, and an embedded AI Business Strategist.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Verify `.env` has the correct Backend API endpoint:
```env
VITE_API_URL=http://localhost:5001/api
```

### 3. Run Development Server
```bash
npm run dev
```
Access the client at `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```
